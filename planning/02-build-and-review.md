## How posts were converted (`scripts/lib/html-to-md.mjs`)

- Drupal's own display filters were re-run first: line breaks into paragraphs (on both formats), Filtered HTML's tag allow-list, and bare URLs into links. The input is exactly what Drupal rendered.
- "One `<div>` per line" posts became paragraphs and line breaks with the same spacing.
- Floated images became `<img class="float-right" width height>` (raw HTML, since Markdown has no floats). On phones they stack instead of floating.
- Gray command-output boxes became code blocks. The lane-merge ASCII diagram became a monospaced block that keeps its bold labels. 10px text became `<small>`; the 18px quote became a larger-text class.
- Removed: Gmail markup, `<wbr>`, spacer images, empty spacer paragraphs and inline styling such as colors and fonts. The new theme takes over spacing.
- Turned off: Astro's automatic curly quotes, so the original straight quotes stay.
- Image credits (the old "References" field) are appended as a `### References` section on the two posts that had them.
- Re-run anytime: `node scripts/migrate-drupal.mjs` and `node scripts/import-wp-pages.mjs`. **Both overwrite their output**, so make hand edits after deciding you won't re-run them, or add the fix to the script's `FIXUPS`.

## Gemini research: verdicts

- **R1 (image URLs): don't trust these.** Several timestamps are repeating digit patterns (`20110303030303`, `20110606060606`, `20120401101010/11/12`). Some snapshots predate the posts that uploaded the files: `yahoo pipes.png` is dated May 2010 for an Aug 2012 post, `CMD32.png` Nov 2010 for a Jun 2011 post. Filenames like `android200.jpg` (really `android_200.jpg`) may just be copy-paste damage. I couldn't check from here because the container blocks archive.org. `scripts/wayback-fetch.sh` queries the archive directly instead.
- **R2 (Disqus):** Not pursued; you decided to drop comment history. (Was: plausible; you'd need to log into the Disqus account.) Drupal recorded 0 comments locally, so it's unknown whether any existed. Low priority.
- **R3 (redirects):** Correct, and implemented: Astro `redirects` with a canonical tag on every page.
- **R4 (versions):** Still wrong. It repeats `@astrojs/mdx@4.1.0` (needs Astro 5) while pinning Astro 7. The "Sätteri" Markdown engine part is real: Astro 7.4.4 depends on `@astrojs/markdown-satteri`. Its warning about strict HTML didn't apply here; all the raw HTML built cleanly. Pins used, all at least 3 days old: astro 7.4.4, @astrojs/sitemap 3.7.4, tailwindcss and @tailwindcss/vite 4.3.3, @tailwindcss/typography 0.5.20, turndown 7.2.4. MDX and TypeScript aren't needed. `npm audit` reports one moderate issue in a build-time dependency of the typography plugin (postcss-selector-parser); it doesn't reach the built site.
- **R5 (dark mode):** Correct, and implemented. The script runs before first paint, so there's no flash.
- **R6 (converter):** Turndown is used, with custom rules for the legacy markup.
