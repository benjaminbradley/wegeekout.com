# wegeekout.com

Static archive of the We Geek Out! WordPress site (Twenty Twenty theme), captured on 2026-10-26 and published from `docs/` via GitHub Pages at wegeekout.com. It was captured with wget, cleaned of dynamic WordPress features, links made relative, and verified.

Visible changes: the contact form now submits through web3forms (reCAPTCHA and Akismet removed, honeypot added); site search, the comment form and the "Powered by WordPress" footer link were removed (the footer now reads "No longer powered by WordPress").
