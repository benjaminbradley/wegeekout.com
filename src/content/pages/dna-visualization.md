When I found out that I could download my raw DNA data from 23andMe.com, I immediately wanted to create a visual interpretation of that data.

A python script reads the genomic data and uses it to generate a forest of fractal trees. Each tree uses the data for a single chromosome. Larger chromosomes yield bigger trees. The size and angles of the branches are influenced by the genes on the chromosome.
